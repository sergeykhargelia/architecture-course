**Общие сведения о системе**

Система обеспечивает удобный онлайн-доступ к книгам для пользователей, а также эффективное управление процессом их покупки и продажи. Также система предоставляет функциональность ведения списка желаемых покупок для пользователей, пополнения каталога доступных книг для сторонних продавцов и загрузку каталога доступных книг для передачи партнёрам.

**Architectural drivers**

**Функциональные требования:**

* Веб-интерфейс и поддержка веб\-сервисов для взаимодействия с другими системами.  
* Процесс продажи книг включая оплату через интернет.  
* Функционал онлайн корзины: добавление и удаление книг.  
* Возможность ведения списка желаемых покупок.  
* Опция отмены заказа до его отправки.  
* Поддержка различных методов оплаты: кредитной картой и по счету.  
* Возможность создания запроса на возврат книг.

**Интеграция и совместимость:**

* Возможность встраивания мини-каталога на сайты партнеров.  
* Данные мини-каталога в формате XML для передачи между системами.

**Управление учетными записями пользователей:**

* Создание учетной записи пользователя с сохранением персональных данных.  
* Ведение основного списка учетных записей в центральной базе данных.  
* Проверка пароля при входе.

**Поиск и взаимодействие с контентом:**

* Возможность различных методов поиска книг: по заголовку, автору, ключевому слову, категории.  
* Возможность оставлять отзывы с рейтингом и модерирование отзывов администраторами.  
* Возможность размещения редакторских отзывов.

**Поддержка сторонних продавцов:**

* Возможность добавлять свои каталоги книг в основной каталог для сторонних продавцов.

**Масштабируемость:**

* Поддержка до 100 тыс. учетных записей пользователей в первые 6 месяцев и до 1 млн. пользователей в будущем.  
* Обработка до 1000 одновременно подключенных пользователей (10000 после 6 месяцев).  
* Обслуживание 100 поисковых запросов в минуту (1 тыс./мин. после 6 месяцев).  
* Обработка 100 покупок в час (1 тыс./час после 6 месяцев).

**Пользовательский интерфейс**

Обеспечивает взаимодействие пользователей с системой через веб\-страницы. Позволяет пользователям регистрироваться, входить в систему, оставлять отзывы, искать книги, добавлять их в корзину и оформлять заказы. Также позволяет сторонним продавцам дополнять каталог книг, партнёрам \- скачать мини-каталог в формате xml.

**Серверное приложение**

Обрабатывает бизнес-логику системы. Управляет запросами от пользовательского интерфейса, взаимодействует с базой данных и реализует функции регистрации, оплаты, модерации отзывов, пополнения каталога доступных книг и загрузки мини-каталога для партнёров. Содержит следующие модули:

* Модуль регистрации и аутентификации  
* Модуль отзывов  
* Модуль управления каталогом

**База данных**

Хранит информацию о пользователях, книгах, заказах и отзывах. Обеспечивает доступ к данным для серверного приложения.

**Система оплаты**

Обрабатывает платежи пользователей. Позволяет пользователям производить оплату через различные платежные системы и обеспечивает безопасность транзакций.
