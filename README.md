# Roguelike игра

Данный репозиторий содержит простую Roguelike игру, состоящую из нескольких уровней. Чтобы перейти на следующий уровень, нужно добраться до цели, которая обозначается, как :trophy:

В ходе игры персонаж двигается по прямоугольному полю, некоторые клетки которого заблокированы, а также в некоторых клетках находятся различные предметы, влияющие на характеристики персонажа. Вам видны не все клетки, а лишь некоторая окрестность уже посещённых вами клеток (то есть вы открываете клетки по мере исследования карты). 

Управление персонажем производится с помощью стрелочек на клавиатуре. Для выхода из игры нужно нажать на клавишу `q`. 

## Установка зависимостей
Зависимости проекта перечислены в файле [requirements.txt](./requirements.txt). Их можно установить с помощью любого менеджера зависимостей. Например, для `pip` это делается следующим образом:
```
pip3 install -r requirements.txt
```

## Запуск игры
Игру можно запустить с помощью команды 
```
python3 main.py
```
